# Fotos — qué reemplazar

Hoy la página usa fotos **temporales de Unsplash** (enlaces directos en el HTML, marcadas con el comentario `TEMPORAL`).
Guarda aquí las fotos reales con estos nombres y cambia el `src` de cada `<img>` por la ruta local.

Recomendado: JPG o WebP, < 250 KB cada una, fondo claro y luz cálida (como en el Instagram).

| Archivo | Dónde va | Tamaño sugerido |
|---|---|---|
| `logo.svg` | Header y footer | vector |
| `hero.jpg` | Inicio, foto en arco (vertical, modelo con joyas) | 1200×1500 |
| `hero-detalle-esmeralda.jpg` | Octágono pequeño del hero | 600×600 |
| `coleccion-plata.jpg` | Colección Plata | 800×1000 |
| `coleccion-esmeraldas.jpg` | Colección Esmeraldas | 800×1000 |
| `coleccion-rodio.jpg` | Colección Rodio | 800×1000 |
| `coleccion-acero.jpg` | Colección Acero | 800×1000 |
| `coleccion-accesorios.jpg` | Colección Accesorios | 800×1000 |
| `productos/<nombre>-1.jpg` | Foto principal (joya sola, fondo claro) | 1000×1250 |
| `productos/<nombre>-2.jpg` | Foto al pasar el mouse (joya puesta) | 1000×1250 |
| `mujer-valiente.jpg` | Bloque "Para ella" | 1000×1200 |
| `linea-hombre.jpg` | Bloque "Para él" | 1000×1200 |
| `esmeralda-historia-1.jpg` y `-2.jpg` | Sección de la esmeralda | 800×1000 / 600×600 |
| `instagram-1.jpg` … `instagram-6.jpg` | Grilla de redes | 600×600 |
| `og-compartir.jpg` | Vista previa al compartir el enlace | 1200×630 |
